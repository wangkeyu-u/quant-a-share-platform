# A-share backtesting workbench

本地日线策略研究工具，包含行情缓存、规则策略、GBM 训练和模拟账户。训练标签按可用日期过滤，收盘信号在下一根行情开盘执行。

## 最近修复：历史行不等于已知标签

旧实现先计算未来收益，再把特征按历史日期截取。预测第 t 日时，最近几行的回归标签仍含 t 日及之后的价格。单股训练、跨股票训练和交叉验证都有这个缺口；旧 README 的“严格无前视”表述不成立。

现在每个训练样本都记录 `feature_date` 和 `label_end`。训练只接收 `label_end < cutoff` 的样本；holdout 和 CV 按独立日期分组，跨股票的同日记录不会落入训练与验证两侧。详见 [故障与修复记录](docs/label-availability.md)。

## 收盘信号的成交时点

回测与模拟账户共用 `PaperTrader.step_bar`：先执行上一根信号，再按本根收盘价估值，最后保存本根信号。首根保持现金，末根信号不会被强行成交；基准在第二根开盘买入，使用相同仓位比例、手续费和滑点。报告标记 `close-signal-next-observed-open-v1`。

三根合成行情的旧实现会凭空赚到信号生成后的隔夜跳空，修复后不再获得这段收益。见[成交时点与复现](docs/execution-timing.md)。

## 设计选择

- 分类器预测次日方向；回归器预测 `horizon` 个观察交易日后的收益。`horizon` 现在真正决定回归目标，默认 5。
- 对分类器与回归器使用相同的保守训练集：两种标签都已知才训练。这样会少用一些已经有分类标签的近期行。
- 验证窗口前删除尚未到期的标签，按每只股票实际观察日期处理停牌/缺行；固定行数 gap 不适合不同交易日覆盖的 pooled 数据。
- 最新特征不需要未来标签才能预测，因此不再强制把最后 `horizon` 行信号置零。

## 验证

十九项离线回归测试覆盖成交时点、跳空、手续费、账户重置、基准/报告一致性，以及未来价格扰动、按可见历史重建训练输入、horizon/缺失标签、跨股票日期隔离及真实 sklearn 双模型训练/保存。真实 estimator 检查使用小型网格与合成数据，只验证集成行为。

```bash
python -m pip install numpy pandas scikit-learn joblib
python -m unittest discover -s tests -p 'test_*.py' -v
```

把可用日期过滤恢复为旧的 date-only 规则时，两个因果回归用例失败；修复版本通过。这里没有发布新的市场收益或模型准确率结论。

## 仍然存在的限制

- 下一根观察行情开盘价只是模拟成交假设；缺失行情、涨跌停、停牌、成交量与整手约束没有撮合模型。成交 `pnl`/胜率仍按未扣费价差统计，权益曲线则扣除手续费和滑点。
- 复权行情不是已证明的 point-in-time 数据；幸存者偏差、标的选择及策略寻优的外层隔离仍需独立验证。
- MACD 等特征带价格量纲；pooled 训练的跨股票可迁移性未验证。
- 行情请求失败会回退到合成数据。现有流水线未提供足够严格的数据来源隔离，不能将其报告直接当真实市场成绩。
- 旧模型及旧评估不具备本次时间边界协议；需要重新训练，不能仅修改标签描述后继续使用原分数。

## 运行

```bash
python -m pip install -r requirements.txt
python run.py
```

[运行与扩展](OPERATIONS.md) 提供流水线、可选模型网关、桌面界面及策略扩展说明。所有交易均为本地模拟；本轮验证没有访问行情服务、外部模型或账户。
